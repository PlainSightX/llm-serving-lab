# R2发布机制检查点：真实质量门未通过

R2尚未完成。多版本控制、请求绑定、灰度/排空/回滚合同已实现并通过软件测试；两个真实模型均未通过事前固定的服务质量门，因此完整真实发布试验停在资格阶段，没有实际发布/回滚成功结论。

## 已交付的代码

- 参数身份按tensor名称、dtype、shape与实际数据计算，不受说明文件和重新分片影响；注册前后核对完整磁盘工件与worker装载清单。
- 版本状态、面板身份、worker代际与路由代际持久化；切换采用CAS，默认路由和显式版本均检查接纳状态。
- 请求在计数前固定实例；计数、排队、流式、取消及未确认释放均保留该绑定和租约。未排空不能退休。
- 同一runtime跨版本去重；控制者重启保留unknown与原实例身份。实例重新绑定必须重新资格及提交路由，不能自动承接旧流量。
- 管理接口只接纳启动时登记的版本，使用本地密钥；真实资格调用也进入账本，超时计数未结束时不提前释放租约。

软件反例包括切换发生在计数/排队/流式期间、坏候选不改变active、跨版本重复key、未确认清理不能退休、退休后回滚拒绝、显式rebind及旧调用恢复。最终Windows97项通过/1项Linux跳过，Linux98项通过。替身测试不能代替真实发布验收。

## 审查与恢复边界

独立代码审查发现三处重要问题并已修复：活动版本换代后默认路由提前使用新实例；资格计数超时后提前解除租约；当前磁盘参数身份未与旧worker装载工件核对。修复分别补了回归检查，完整回归通过。A轮早于最后一项防漂移修复；它保留原源码与输出，不标成新代码的完整真实验收。1.7B独立资格使用了注册前后工件校验。

所有本轮自有GPU worker和网关已停止，原始失败、官方模型、锁环境及审核输入保留。未训练、未租云、未修改Q1、旧P1拒绝结果或其他项目。此交付是可恢复工程检查点，不是R2发布资格完成。

## 复盘与继续条件
