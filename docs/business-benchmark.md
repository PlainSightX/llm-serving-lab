# 业务任务与比较合同

用途更新（v0.3整改）：本文保留wind-plan-v2的实际合同，作为协议/执行器回归与历史诊断；不再承担未来研究任务资格。当前工作顺序见整改安排，研究重建由Q1负责。下文的旧试点安排不自动成为下一步。

当前实现是 `wind-plan-v2` 合成协议试点，面向单站点、单预测步长的风电实验比较。数据由项目生成器构造，不是真实风场测量或公开数据复现；所有数字都应按这个来源解释。原始 v1 试点因提前暴露未来规则被判无效，输出保留，不并入新结果。

## 模型承担什么

每个任务公开当次请求、当前规则、预期时间网格、观测、多个实验的预测记录及单位。模型生成受限 JSON 计划：指定实验、指标、共同支持、单位、覆盖门和 `compare/abstain` 操作。它必须从实际观测与两个实验求时间交集，决定允许比较还是拒绝。只复制请求和规则不能总是通过。

执行器实际换算 MW/kW、按时间连接、计算 MAE/RMSE、覆盖率与排名。它不允许任意代码、SQL、路径或额外操作，也不暗中改写模型的门槛。独立 oracle 使用另一条直接聚合路径；评价同时检查关键计划义务和真实计算结果。手算反例覆盖单位、公共支持导致赢家变化、MAE/RMSE 排名逆转、覆盖不足、空交集及数学等价阈值。格式不合格仍保留为首次失败。

目前只有覆盖分支依赖模型对数据的判断；单位转换、连接和误差算数由程序负责。这是可核验的业务协议基础，不能称多轮 Agent、完整研发分析能力或持续学习成果。

## 时间与切分

冻结 30 个任务：8 个 train、12 个 dev、10 个 holdout。先 v1 训练/开发，再 v2 训练/开发；提示只提供当次规则。v1 按共同样本数准入，v2 按共同样本占预期时间网格的比例准入。所测是应用明确给出的规则，不是自行发现新规则。

训练使用单个因素，开发使用配对因素，保护流包含三因素组合、与训练匹配难度的有效技能、规则变化和空交集拒绝。因素是单位差异、记录乱序、缺失记录及无关实验。实体、时间键与输入对象跨切分隔离；组合保护与开发结构不同。有效技能面板故意匹配训练难度，不能把它称结构完全独立。

本轮只导入 train/dev；保护流独立保存且不进行模型调用。生成器和答案对开发者可见，所以保护指执行/训练隔离，不能称外部盲测。正式研究前还须平衡组合面板中的比较与拒绝分支，并加入独立真实数据和多种业务决策结构。

## 两组可执行基线

两组使用相同固定基座、当前规则、工具合同和生成上限，工作区隔离。采用自然闭环：各组只拥有自己已经成功执行的训练经历；轨迹差异属于比较结果，不能解释为固定历史下的因果效应。

- frozen：不注入历史经历。
- memory：仅检索过去 train 的实际模型输出；必须有完整回执且验证通过，反馈在当前任务前可用。排除 dev/holdout、手工结果、失败、未来反馈与过期规则。公开输入概要做 BM25 排序，最多 3 条、2600 字符；不读取隐藏因素、family 或 expected 排序。每条来源与实际模型输入绑定。

这只是可审计的初始记忆基线。整条过滤旧规则会丢掉有效的单位/对齐技能，正式强记忆基线需按规则依赖拆分经验并在开发流验证检索质量。若 `with_memory=0`，即使运行两组也不能声称已验证实际记忆注入。

任务开始前冻结模型、arm、记忆策略和生成参数；报告逐条核对真实请求，不能把别的配置计入预登记组。完成回执之后中断，可以复用原输出补齐缺失的训练反馈，禁止新生成。失败、未知、格式错误和未完成任务都保留在分母。

## 五组正式比较的后续门槛

| 组别 | 参数 | 外部经历 | 本轮状态 |
|---|---|---|---|
| 冻结 | 固定基座 | 无 | 可执行协议试点 |
| 冻结+记忆 | 固定基座 | 初始版本化检索 | 可执行协议试点，尚非最终强基线 |
| 周期 LoRA+回放 | 真实周期更新 | 无 | 等待业务数据/模型资格 |
| LoRA+记忆 | 同一更新预算 | 与记忆组同一实现 | 待实施 |
| 候选筛选/门控 | 仅改变被检验的筛选机制 | 与对照同一实现 | P3 待实施 |

先做相同历史下的机制对照，再做自然闭环；固定更新预算、回放容量和数据可用时点。保存旧/新参数与记忆快照并做交叉消融。开发用于选择，保护只用于最终评价。不能用当前小模型的格式错误证明权重更新必要，也不能用总通过率掩盖有效旧技能退化。

后续进入真实训练前先检查：任务是否有足够辨别力、结构化输出是否可靠、可验证经历是否充足、错误是否来自业务决策而非接口格式。当前合成任务只能检验实现；真实研究还需更丰富流程、合理重复与强基线。两独立 GPU 节点的部署和故障验收继续保留为后续工程交付。
